# templates/

Reusable scaffolding meant to be copied **into other repositories** — not part of Symphony's
own product or docs build. Nothing here is imported or deployed by this repo.

## Contents

- **`docs-site-porting-guide.md`** — a complete, self-contained recipe for standing up a
  Docusaurus 3 documentation site with client-side Mermaid rendering, a CI Mermaid-validation
  step, and GitHub Pages auto-deploy. It mirrors the setup that lives in this repo's
  `docs-site/`, but with placeholders so it can be dropped into **any** repo (even an empty one).
  Hand it to an AI agent along with the prompt in its Appendix B, or follow the steps by hand.
